# Smart Start Academy & Daycare — Website

Premium static website for Smart Start Academy and Daycare, Orange Grove, Johannesburg.

## Open the site

Double-click `index.html`, or from this folder:

```bash
python -m http.server 4173
```

Then visit http://localhost:4173
